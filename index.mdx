## 01 产品概述

ClaimAgent 是专为保险行业打造的 AI 驱动型理赔材料智能处理平台。它依托业内领先的文档解析与理解技术，可对上传的理赔材料自动完成智能质检、精准分类与深度信息抽取，并输出结构化数据、真实性研判及风险提示。该平台能帮助保险公司与第三方管理机构（TPA）将先进的智能处理能力无缝集成至现有理赔流程中，从而实现人工录入与复核成本的显著降低，并提升风险识别能力。

## 02 产品价值

*   **智能质检与分类**：上传材料自动进行质量检测（模糊、翻拍等）与精准分类，从源头把控数据质量。
*   **深度信息抽取**：基于领先的文档解析技术，自动提取 OCR 及结构化字段，减少人工录入。
*   **智能辅助风控**：自动生成案件时间线、进行发票真伪验真及材料齐全性检查，辅助快速决策。
*   **灵活集成**：支持同步/异步两种接入方式，可无缝嵌入客户现有的理赔流程中。

## 03 使用流程

1.  **创建案件并上传材料**：`POST /claim/create`
2.  **选择处理阶段**：通过 `stages` 参数指定处理环节
3.  **同步/异步获取结果**：
    *   **同步**：请求等待处理完成后返回
    *   **异步**：先返回 `claim_id`，处理完成后再查询结果（可配置 `callback_api`）
4.  **按需查询结果**：分类/抽取/时间线/齐全性/真伪分别有查询接口
5.  **单图质检（可独立使用）**：`POST /image_quality`

## 04 核心概念

*   **Base URL**：`/doc-agent/api/v1`
*   **claim_id**：案件 ID（创建案件成功后返回）
*   **material_id**：材料 ID（每份上传材料对应一个）
*   **stages**：处理阶段（只能选指定组合）
    1.  分类
    2.  抽取
    3.  时间线
    4.  真实性校验
    *   支持组合：`[1]`、`[1,2]`、`[1,2,3]`、`[1,2,4]`、`[1,2,3,4]`
*   **Status**：通用状态枚举
    *   `0` 未开始 / `1` 进行中 / `2` 成功 / `3` 失败 / `4` 跳过

## 05 接入方式：同步/异步

从接入方式上，ClaimAgent 支持两种典型用法：

*   **同步处理**：一次请求等待处理完成，直接获取结果，适合 demo、低并发或需要即时展示结果的交互场景。
*   **异步处理**：创建案件后返回 `claim_id`，后台处理完成后再查询结果（也可配置回调），适合生产环境批量、长耗时任务与更稳定的吞吐。

**适用场景：**
*   **同步（`is_async=false`）**：适合 Demo、交互式页面、小批量；一次请求直接获取结果
*   **异步（`is_async=true`）**：适合生产批量与长耗时；创建后获取 `claim_id`，完成后查询结果或等回调（`callback_api`）

## 06 核心接口一览

**统一前缀**：`/doc-agent/api/v1`（所有接口需要 API Key 认证）

*   **创建案件**：`POST /claim/create`
*   **分类结果**：`GET /claims/{claim_id}/materials/category-mappings`
*   **抽取结果**：`GET /claims/{claim_id}/materials/extractions`
*   **时间线**：`GET /claims/{claim_id}/timeline`
*   **齐全性**：`GET /claims/{claim_id}/materials/completeness`
*   **真伪**：`GET /claims/{claim_id}/materials/validity`
*   **单图质检**：`POST /image_quality`
