## 01 产品概述

平台基于业内领先的文档理解、多模态识别及智能图像处理与审核技术，围绕保险理赔与核保场景中"材料复杂、质量参差、结构混乱"的核心问题，提供从**材料接入**、**质量检测**、**图像优化**、**文档整理**、**分类识别**到**信息抽取**的一体化处理能力。

<Frame caption="四步构建理赔材料自动化路径">
  <img src="/images/guide/pipeline-steps.png" />
</Frame>

针对保险业务中常见的多来源、多格式（图片、PDF、扫描件、拍照件等）材料，Claim Agent 可自动完成：

- 材料质量检测与风险识别
- 图像标准化处理
- 多页文档归并与结构整理
- 材料自动分类
- 关键字段结构化抽取

并最终输出：

- 标准化材料文件
- 材料质量评估结果
- 风险提示信息
- 高精度结构化数据

帮助保险公司及第三方管理机构（TPA）实现从"杂乱低效的原始材料"到"标准化、结构化、可直接使用数据"的转变。

平台能力高度 API 化，支持以**工作流方式灵活编排各类处理能力**，可无缝集成至现有理赔、核保、风控系统中，显著降低人工录入与复核成本，同时提升材料处理效率与风险识别能力。

## 02 核心价值

### 2.1 材料标准化前处理能力

<Tip>
在 OCR 识别与理赔核保等下游任务之前，优先解决材料"是否可用"的问题，将风控前移，降低审核压力，同时提升整体处理效率。
</Tip>

Claim Agent 可自动检测影像件与电子件的质量风险，包括模糊、完整性缺失、光斑、阴影、复印件、翻拍件等问题，并支持针对异常材料进行标记、重传或拦截处理。

同时，平台提供图像切边矫正、图像增强、图像水印去除及智能高清等处理能力，实现将非标准化材料转化为标准化输入，从源头提升下游识别与审核效果。

<Frame caption="材料标准化前处理 — 质检与风险标记界面">
  <img src="/images/guide/quality-check-ui.png" />
</Frame>

### 2.2 多材料自动整理与结构化能力

<Tip>
通过减少人工拆分、归类与排序操作，平台可帮助企业显著降低文档整理成本，并提升整体处理效率。
</Tip>

在保险场景中，材料通常呈现多来源、多页数、结构混乱的特点，如出院小结、门诊病历等文件，需完整整理后才具备业务处理价值。

针对材料混乱问题，Claim Agent 提供多图混贴自动切分、多页文档自动归并与排序、材料自动分类等能力，实现材料结构的自动化整理。

<Frame caption="多材料自动整理 — 文档归并与排序界面">
  <img src="/images/guide/material-organize-ui.png" />
</Frame>

### 2.3 精准信息抽取与结构化输出

<Tip>
通过将非结构化内容转化为高精度结构化数据，平台有效减少人工录入与校验工作，为后续业务处理与风控提供标准化数据支撑。
</Tip>

在完成材料标准化处理与结构整理后，Claim Agent 可基于文档理解能力，对不同类型材料进行精准信息抽取，并输出结构化数据，直接对接理赔与核保系统。

平台支持按材料类型灵活配置抽取规则，包括字段定义、抽取逻辑及输出格式。用户可根据业务需求，自定义不同票种或文档类型的关键字段（如费用信息、身份信息、就诊信息等），并持续优化抽取策略。

<Frame caption="精准信息抽取 — 结构化字段与表格输出界面">
  <img src="/images/guide/extract-result-ui.png" />
</Frame>

### 2.4 工作流化原子级能力，灵活部署与集成接入

<Tip>
平台支持节点级参数配置、结果可追溯与调试，同步支持公有云以及私有化两种部署方式，并提供标准化接口接入能力，可无缝集成至现有理赔、核保及风控系统中。
</Tip>

Claim Agent 将各类处理能力拆解为原子节点，企业客户可根据自己实际业务流程灵活编排工作流，支持按不同业务场景快速构建处理流程。
