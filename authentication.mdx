## 01 访问凭证获取

快速获取您的 `x-ti-app-id` 和 `x-ti-secret-code`。

点击链接获取 API Key：[TextIn 工作台 - 账号与开发者信息](https://www.textin.com/console/dashboard/setting)

1. 在 Claim Agent 产品页面点按右上角的个人资料图标
2. 点击「账号与开发者信息」进入工作台相应页面

<Frame caption="步骤 1-2：点击右上角个人资料图标，进入「账号与开发者信息」">
  <img src="/images/guide/credential-step1.png" />
</Frame>

3. 单击"复制"图标获取您的 `x-ti-app-id` 和 `x-ti-secret-code`

<Frame caption="步骤 3：在工作台复制 x-ti-app-id 和 x-ti-secret-code">
  <img src="/images/guide/credential-step2.png" />
</Frame>
