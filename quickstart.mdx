## 01 准备信息

*   **Base URL**：`{HOST}/doc-agent/api/v1`
*   **鉴权**：所有接口均需要 API Key
*   **推荐先跑通**：`stages=[1,2]`（分类 + 抽取）

## 02 创建案件并上传材料（异步示例）

`POST /claim/create`（`multipart/form-data`）

**字段**：
*   `files`：材料文件（可多份）
*   `stages`：重复传参（例如传两次 `stages=1` 与 `stages=2`）
*   `is_async=true`
*   `policy_no`、`insured_name`：必填
*   `callback_api`：可选（异步完成后回调）

**示例（curl）**：

```bash
curl -X POST "{HOST}/doc-agent/api/v1/claim/create" \
  -H "x-api-key: {API_KEY}" \
  -F "policy_no=YOUR_POLICY_NO" \
  -F "insured_name=YOUR_INSURED_NAME" \
  -F "files=@/path/to/material-1.pdf" \
  -F "files=@/path/to/material-2.jpg" \
  -F "stages=1" \
  -F "stages=2" \
  -F "is_async=true"
```

**返回**：
*   `claim_id`
*   [materials[]](/api-reference/endpoint/get_material_category)（包含 `material_id`/`file_name`/`file_type`/`file_size`/`status` 等基础字段）

## 03 查询结果（按需调用）

可选通过 `material_ids` 过滤只取部分材料；不传则返回全部。

**获取分类**：
```bash
curl "{HOST}/doc-agent/api/v1/claims/{claim_id}/materials/category-mappings" \
  -H "x-api-key: {API_KEY}"
```

**获取抽取**：
```bash
curl "{HOST}/doc-agent/api/v1/claims/{claim_id}/materials/extractions" \
  -H "x-api-key: {API_KEY}"
```

**获取齐全性**：
```bash
curl "{HOST}/doc-agent/api/v1/claims/{claim_id}/materials/completeness" \
  -H "x-api-key: {API_KEY}"
```

**获取时间线**：
```bash
curl "{HOST}/doc-agent/api/v1/claims/{claim_id}/timeline" \
  -H "x-api-key: {API_KEY}"
```

**获取真伪**：
```bash
curl "{HOST}/doc-agent/api/v1/claims/{claim_id}/materials/validity" \
  -H "x-api-key: {API_KEY}"
```

## 04 同步模式（需要一次拿到结果时）

将 `is_async=false`，并按需设置 `stages`。同步返回会包含对应阶段的结果字段：

*   `[1]`：`materials.category` + `completeness_result`
*   `[1,2]`：增加 `materials.extract_result`
*   `[1,2,3]`：增加 `timeline_result`
*   `[1,2,4]`：增加 `materials.verify_vat_ret`、`materials.ps_ret`
*   `[1,2,3,4]`：同时包含时间线与真实性结果
